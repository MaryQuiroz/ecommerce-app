# Bella Beauty - E-commerce de Productos de Belleza

Un e-commerce moderno desarrollado con React y Vite, especializado en productos de belleza y cuidado personal. La aplicación incluye todas las funcionalidades esenciales de una tienda online como catálogo de productos, carrito de compras, proceso de checkout, perfil de usuario, y más.

## 🌐 Demo

Visita la demostración en vivo: [Bella Beauty E-commerce](https://MaryQuiroz.github.io/ecommerce-app/)

## ✨ Características

- **Diseño Responsivo**: Experiencia de usuario optimizada para dispositivos móviles y escritorio
- **Catálogo de Productos**: Navegación por categorías, filtros y búsqueda de productos
- **Carrito de Compras**: Agregar/eliminar productos, actualizar cantidades, aplicar códigos promocionales
- **Proceso de Checkout**: Formulario de envío, opciones de pago, resumen de pedido
- **Perfil de Usuario**: Gestión de información personal, direcciones, historial de pedidos y lista de deseos
- **Autenticación**: Registro de usuarios, inicio de sesión, recuperación de contraseña

## 🛠️ Tecnologías

- **Frontend**: React 19, React Router v7, Context API para gestión de estado
- **Estilos**: Tailwind CSS 4
- **Construcción**: Vite 6
- **Despliegue**: GitHub Pages

## 🚀 Instalación y Uso

1. Clona este repositorio:
   ```bash
   git clone https://github.com/MaryQuiroz/ecommerce-app.git
   cd ecommerce-app
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

4. Construye para producción:
   ```bash
   npm run build
   ```

5. Despliega en GitHub Pages:
   ```bash
   npm run deploy
   ```
